# Approved native art — staged integration

This commit preserves the approved native-resolution character and effect sheets and eight full-size arenas. These are source assets for the revision; existing scenes still use their previous SpriteFrames until the animation importer and combat integration are committed.

- Thin, angular character designs: Mulan, Aladin, Ariel, Puss, Alice, João and Maria.
- Preserve the approved Peter and Little Match Girl designs.
- Ten effect atlases: six basic-attack frames and six ultimate frames each.
- Eight separate HD arena backgrounds.

Character poses present here: Alice and Mulan idle/variation/walk/attack; Peter and Little Match Girl idle/variation/walk/attack; Aladin, Ariel, Puss, João and Maria idle/variation. Rapunzel's new body sheets and the remaining walk/attack revisions are not included in this asset checkpoint.

Effects use six columns and two rows, basic attacks above ultimates. Idle/variation sheets use four columns and two rows (Little Match Girl uses the first two rows of its combined sheet); walks use four by four; attacks use five by two.
