# Android 1.0.1 — códigos de resgate

- Configurações → Códigos → `500.001` → Resgatar (ou confirmar no teclado).
- Libera todos os personagens permanentemente neste dispositivo, sem gastar memórias, liberar bênçãos ou alterar a run atual.
- O resgate é idempotente. Um código inválido não altera o progresso; uma falha de gravação desfaz o desbloqueio e permite tentar novamente.
- O campo está disponível no Android e no PC; sessões temporárias de DEBUG precisam ser encerradas antes do resgate permanente.
